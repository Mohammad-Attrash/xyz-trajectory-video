# Changelog

All notable changes to this project will be documented in this file.

The project uses semantic versioning where practical.

## [Unreleased]

### Planned

## [1.0.0] - 2026-09-22

### Added

- Multi-frame XYZ trajectory reader.
- H.264 MP4 video generation.
- Exact top and side views.
- Smooth shaded three-dimensional atom spheres.
- Element-specific atom colors and rendering radii.
- Element-specific distance cutoffs for bond visualization.
- Two-colored heteroatomic bonds.
- Bond trimming at atom surfaces.
- Fixed coordinate limits throughout each trajectory.
- Independent side-view magnification.
- Optional simulation-time annotation.
- Final-frame hold duration.
- Command-line interface and Python import interface.
